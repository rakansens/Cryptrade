# Cryptrade プロジェクト概要

## プロジェクトの目的
仮想通貨取引支援のための高度な市場分析プラットフォーム

## 核心的な価値提案
- リアルタイム市場データ分析
- AI駆動の取引意思決定支援
- 高性能なチャート分析機能
- マルチタイムフレーム対応

## 技術スタック
- **フロントエンド**: Next.js, TypeScript, Zustand
- **バックエンド**: Node.js, API Routes
- **データ**: Binance API, WebSocket接続
- **AI/ML**: Mastra エージェントフレームワーク
- **テスト**: Jest, Testing Library

## 現在の重要課題
1. **パフォーマンス問題**: enhanced-market-data.service.ts (678行) の応答時間2.5秒
2. **責任過多**: 8つの異なる責任が1つのサービスに集約
3. **アルゴリズム複雑度**: O(n²)による性能劣化
4. **テスタビリティ**: モノリシックサービスによる低いテスト可能性

## Phase 2.1 目標
- マイクロサービス化による責任分離
- O(n log n)アルゴリズムへの最適化
- 応答時間80%改善（2.5秒→0.5秒）
- 100%テストカバレッジ達成
