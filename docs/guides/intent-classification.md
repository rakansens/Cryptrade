# Intent Classification Keywords

This document lists the keywords used to classify user queries.

## Price Inquiry
- 価格, price, いくら, how much, 値段, value, rate, レート
- 相場, quote, prc, 現在値

## UI Control
- チャート, chart, 表示, display, 切り替え, switch, 変更, change, 描画, draw
- disp, sw, chg, tf, zoom, ズーム, ma, rsi, macd, bb, ind

## Trading Analysis
- 分析, analysis, 投資, investment, 取引, trading, 戦略, strategy, リスク, risk
- ta, fa, entry, exit, tp, sl, 評価, 見解

## Conversational
- こんにちは, hello, ありがとう, thank, help, ヘルプ
- thx, pls, yo, 助けて

These abbreviations were gathered from real usage logs. Update tests when modifying this list.
