# Cryptrade 開発要件定義書

## 1. サービス概要

### 1.1 サービス名
**Cryptrade** - AI駆動暗号通貨取引支援プラットフォーム

### 1.2 サービスコンセプト
最先端のAI技術を活用して、暗号通貨トレーダーに高度な市場分析、リアルタイムの取引提案、直感的なチャート操作を提供する統合プラットフォーム。自然言語処理により、初心者から上級者まで誰もが簡単に高度な分析機能を利用できる。

### 1.3 主要な価値提供
- **AIアシスタント**: 自然言語での市場分析と取引戦略提案
- **リアルタイム分析**: 24時間365日の市場監視と即座の分析
- **統合チャート**: プロフェッショナルグレードのチャート機能
- **自動化された技術分析**: パターン認識、サポート・レジスタンス検出

## 2. 機能要件

### 2.1 AIチャット機能
#### 2.1.1 基本機能
- **自然言語対話**: ユーザーの質問や要求を理解し、適切な回答を生成
- **コンテキスト保持**: 会話履歴を保持し、文脈に沿った対話が可能
- **マルチエージェント**: 専門化されたAIエージェントによる役割分担
  - Orchestrator Agent: ユーザー意図分析とルーティング
  - Trading Agent: 取引分析と戦略提案
  - Chart Control Agent: チャート操作制御
  - Price Inquiry Agent: 価格情報提供

#### 2.1.2 分析機能
- **市場分析**: 現在の市場状況の総合的な分析
- **価格予測**: AI/MLモデルによる価格動向予測
- **取引提案**: エントリー/エグジットポイントの提案
- **リスク評価**: ポジションリスクの評価とアドバイス

### 2.2 チャート機能
#### 2.2.1 基本表示
- **ローソク足チャート**: リアルタイム更新対応
- **複数時間足**: 1分〜月足まで対応
- **ズーム/パン**: 直感的なナビゲーション
- **価格表示**: 現在価格、高値、安値、出来高

#### 2.2.2 テクニカル指標
- **RSI** (相対力指数): 買われ過ぎ/売られ過ぎの判定
- **MACD**: トレンド転換の検出
- **移動平均線**: SMA/EMA対応、複数期間設定可能
- **ボリンジャーバンド**: ボラティリティ分析

#### 2.2.3 描画ツール
- **トレンドライン**: 自動/手動描画
- **水平線**: サポート/レジスタンスレベル
- **フィボナッチリトレースメント**: 重要価格レベルの特定
- **パターン認識**: 三角形、ヘッドアンドショルダー等

### 2.3 リアルタイムデータ
#### 2.3.1 市場データ
- **価格フィード**: Binance WebSocket経由のリアルタイム価格
- **出来高データ**: 取引量の可視化
- **オーダーブック**: 売買板情報（将来実装）
- **約定履歴**: リアルタイム取引履歴

#### 2.3.2 通知機能
- **価格アラート**: 設定価格到達時の通知
- **パターン検出**: チャートパターン形成時の通知
- **AI提案**: 取引機会の自動検出と通知

### 2.4 データ管理
#### 2.4.1 セッション管理
- **会話履歴**: すべてのチャット履歴を保存
- **分析履歴**: 過去の分析結果の参照
- **描画保存**: チャート上の描画を永続化
- **設定保存**: ユーザー設定の保存と復元

#### 2.4.2 ポートフォリオ管理（将来実装）
- **保有資産追跡**: 複数通貨の管理
- **損益計算**: リアルタイムP&L
- **パフォーマンス分析**: 取引成績の可視化

## 3. 技術要件

### 3.1 フロントエンド
- **フレームワーク**: Next.js 15.3.3 (App Router)
- **言語**: TypeScript 5.2.2
- **UI ライブラリ**: React 18.3.1
- **状態管理**: Zustand 5.0.5
- **スタイリング**: Tailwind CSS 3.3.3
- **チャートライブラリ**: Lightweight Charts 4.1.3
- **アニメーション**: Framer Motion 12.16.0

### 3.2 バックエンド
- **ランタイム**: Node.js 18.x以上
- **API**: Next.js API Routes
- **AIフレームワーク**: Mastra 0.10.1
- **AI モデル**: OpenAI GPT-4
- **WebSocket**: カスタム実装 + Binance WebSocket API

### 3.3 データベース
- **メインDB**: PostgreSQL (Supabase)
- **ORM**: Prisma 6.9.0
- **キャッシュ**: Redis (Upstash/Vercel KV)
- **セッションストア**: メモリ/DB ハイブリッド

### 3.4 インフラストラクチャ
- **ホスティング**: Vercel (推奨)
- **エラー監視**: Sentry
- **ログ管理**: 統一ログシステム
- **メトリクス**: Prometheus互換

## 4. 主要な動作フロー

### 4.1 AIチャット分析フロー
```
1. ユーザー入力
   ↓
2. Orchestrator Agentが意図分析
   ↓
3. 適切な専門エージェントにルーティング
   ↓
4. 市場データ取得・分析実行
   ↓
5. 結果生成（テキスト + 提案カード）
   ↓
6. チャートへの自動反映（描画等）
```

### 4.2 リアルタイムデータ更新フロー
```
1. Binance WebSocket接続確立
   ↓
2. 価格データストリーム受信
   ↓
3. データ検証・正規化
   ↓
4. Zustand ストア更新
   ↓
5. React コンポーネント再レンダリング
   ↓
6. チャート・UI自動更新
```

### 4.3 取引提案承認フロー
```
1. AIが取引提案生成
   ↓
2. 提案カード表示
   ↓
3. ユーザーが承認/却下を選択
   ↓
4. 承認時：チャートに描画追加
   ↓
5. 実行結果の記録・学習
```

## 5. API仕様概要

### 5.1 主要エンドポイント
- **チャット**: `/api/ai/chat` - AI対話インターフェース
- **分析**: `/api/ai/analysis-stream` - リアルタイム分析
- **市場データ**: `/api/binance/klines` - ローソク足データ
- **チャート**: `/api/chart/sessions/[id]/drawings` - 描画管理
- **イベント**: `/api/events` - Server-Sent Events

### 5.2 認証・セキュリティ
- **API Key**: OpenAI APIキー（環境変数）
- **CORS**: 設定可能なオリジン制限
- **レート制限**: エンドポイント別の制限
- **入力検証**: Zodスキーマによる厳密な検証
